# ProjetEscapeGame
Here is the branch to test some ideas with Three.Js

## **INSTALLATION**
1) Clone the Project
2) Open Git bash in the project repo
3) Switch to this branch with ***git checkout Feature-Test-Objet-Yoann***
4) Install vite with ***npm install vite***
5) Install three.js with ***npm install three@latest***

## **LAUNCH THE PROJECT**
1) Run vite server with ***npx vite***
2) Open the localhost link in a web client
